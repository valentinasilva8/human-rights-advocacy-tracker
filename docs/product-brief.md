# Product brief

Advocacy Trace is an independent prototype for the FAIRTRIAL / TrialWatch x AI Hackathon, Track 3 (Advocacy and Impact). It is a learning and accountability tool for reading human-rights advocacy. It is not a legal advisor, an automated judge, or a system for predicting case outcomes.

This project is not a product of the Clooney Foundation for Justice, TrialWatch, or Columbia Law School, and it does not claim endorsement or affiliation.

## Question the prototype answers

Show the cases in which TrialWatch advanced a proportionality argument. For each one, show what was argued, what response is documented, and what happened to the defendant afterward.

## Organizing principle

Argument, then documented intervention, then subsequent developments, then defendant outcomes, then evidence and uncertainty.

## What a user can do

1. Filter reviewed arguments by the five freedom-of-expression labels, country, intervention type, date, and verification status.
2. Open one proceeding and read the intervention, the cited passage, later outcome events, and any separate record of whether an authority addressed the argument.
3. Approve, reject, or edit a proposed extraction, and draft a learning brief that stays on the machine until a person copies it.

## What the prototype refuses to do

- Score whether advocacy succeeded.
- Say that an argument caused an acquittal, a release, or any other event.
- Treat a court's summary of an argument as acceptance.
- Treat a missing update as continued detention, an ongoing case, or a failed intervention.
- Rank arguments across jurisdictions.
- Publish or send a learning brief by itself.

## Demonstration boundary

The shipped example is fictional and labeled synthetic. It is there so the screens and tests run without an API key. It is excluded from every real-case count.
